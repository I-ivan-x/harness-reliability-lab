# G0-2 故障、恢复与结束规则

G0-v1 · 2026-11-06 · 基于 `harness-plan-v1`；第 2/3 页。

**F1 注入契约。** 私有计划逐项保存任务/重复编号、操作阶段、尝试序号、注入位置、持续范围/延迟、错误种类及是否已提交。选择项为 `(task_id, repeat, slot, attempt)`；写固定 `write-0`，初始读/修参刷新分别计数。不同模型/策略的 run 映射同一计划，实际幂等键各自隔离。Host/controller 只能看到真实响应或本地超时；不得读取计划或将提交真值加入错误。业务时间固定 `as_of`，预算用单调时钟。

| 种类 | 触发位置、持续范围、提交事实 |
| --- | --- |
| 临时不可用／提交前超时 | 工具执行前（写在事务前）；前 n 次，n=1 或 2；该故障尝试无效果。超时不向 Host 暗示未执行 |
| 持续不可用 | 事务前；本运行全部尝试；无提交 |
| 提交后丢回执／慢回执 | 提交后、交付前；前 n 次响应，n=1 或 2；首次有效写已提交，重放不新增效果 |
| 状态/参数失效 | 初始读后、首次写前真实改变状态一次；旧参数持续不合法，直到有效修正；校验失败不提交 |
| 禁止／需审批 | 当前业务授权校验；本运行维持限制；不得提交，不伪造短暂权限错误 |
| 结果格式损坏 | 结果交付前；前 n 次，n=1 或 2；读无效果，写在提交后损坏回执，结果未知 |

慢响应使用对应提交前/后位置；具体毫秒值在开发期校准，正式冻结前固定。格式故障保持 MCP 消息合法、损坏应用结果 schema；协议错误另记。不得给合法参数注入一条可自动消失的“业务参数错误”。

**F2 可见错误 → 动作。** `isError` 不是恢复授权。适配层区分工具业务错误、JSON-RPC 错误、传输/超时和结果 schema 错误，保留实际观察。

| 可见情况 | P0 | P1 | P2 |
| --- | --- | --- | --- |
| 临时工具故障／读超时 | `SAFE_STOP` | 原参有界重试 | 同 P1 |
| 写超时、传输失败或坏回执 | `SAFE_STOP/UNKNOWN` | 原键原参重放 | 同 P1 |
| 可信、确定未执行/未绑定且可修的业务校验失败 | `SAFE_STOP` | `SAFE_STOP` | 一次重新提案；版本过期先刷新一次 |
| 禁止／需审批 | `REFUSED/HANDOFF_HUMAN` | 相同 | 相同 |
| 明确协议错误、坏模型提案、坏读结果、幂等冲突 | `SYSTEM_FAILURE` | 相同 | 相同 |

P1/P2 每个普通逻辑操作最多 3 次 MCP 尝试（含首次），指数退避加抖动；P0 仅 1 次。修参后的写继续累计原槽位额度。P2 刷新失败即停、不重试刷新；再次可修校验失败则 `SAFE_STOP`，新提案遇临时故障仍按 P1 使用剩余额度；只可写固定目标或终止。可修声明须通过 schema 校验，且覆盖整个槽位、无任何其他可继续提交的旧请求；普通文本不能授权修参。反馈不得提供完整正确请求，Host 不代填业务选项。

**F3 预算与收尾。** 模型调用、MCP 尝试在实际发送前计数；Gate 拦截只耗决策/模型额度。所有失败、刷新、重放、真实退避均计费；无底层隐藏重试。工作截止为总时限减清理窗口；每次等待受剩余工作时间约束。单操作恢复耗尽可 `SAFE_STOP`；仍有策略动作却整体额度不足为 `BUDGET_EXHAUSTED`。取消为 `SAFE_STOP/cancelled`。停派发后在清理时限内排空或终止 MCP，静止后评分；迟到结果只记诊断，不翻转终态/再派发。无法封存标测量无效并暂停，保留原记录；缺失 usage 标未知。

**手推 B（参数失效，非实测）。** S1(v1,内部影响) → p1(普通优先级) → 世界真实变 v2(客户影响) → 写 1 返回可信未执行/未绑定/可修 → P2 读 S2 → 模型据公开需求改为紧急优先级/v2 → 同槽位写 2 成功。P2 正确=1；P0/P1 停止无工单，正确=0；不依赖注入标签。
